# CPS

Lean 4 / Mathlib formalization of the paper *Cumulative Prime Sums and Riemann Zeros: a fine grid,
its ripple, and a family of prime races* (A. Mennillo, version 3, Zenodo, October 2026,
DOI [10.5281/zenodo.23269807](https://doi.org/10.5281/zenodo.23269807)).

Work in progress. The Lean project is in `lean/` (Lean v4.36.0-rc2, Mathlib
`3e1821461a4bc54072a3bd970e5a2ea5d9fd9713`).

| Path | Content |
|---|---|
| `lean/CpsLean/` | the library |
| `lean/Challenge.lean`, `lean/Solution.lean` | statements and proofs compared by Palomar, generated by `lean/scripts/regen.sh` |
| `lean/comparator.json`, `lean/formalization.yaml` | Palomar metadata |
| `lean/docs/` | derivations written before the Lean code |
| `DIVERGENZE.md` | every difference between a Lean statement and the paper, side by side |

Published theorems enter as explicit hypotheses (`def … : Prop`), never as axioms; numerical
certificates likewise, each with its script. No `sorry`; only the axioms `propext`,
`Classical.choice`, `Quot.sound`.
The only `set_option maxHeartbeats 1000000` is on `step4_assembling` (`lean/CpsLean/Step4.lean`): its long
assembly of Lemma A and Steps 2 and 3 exceeds the default limit of 200000 heartbeats.

Build: from `lean/`, `lake build`. Common definitions come from
[lean-base](https://github.com/anthem87/lean-base).

## AI use

The Lean formalization was written with AI assistance under the author's direction. The structured
declaration is the `automation` block of `lean/formalization.yaml`.
